# ลูมิ (LUMI) — ต้นแบบแอปตลาดผลงาน AI ของคนไทย

ต้นแบบเว็บแอปมือถือที่กดใช้งานได้ 18 หน้าจอ ตั้งแต่เปิดแอป เข้าสู่ระบบ ค้นหา ซื้อ ชำระเงิน คลังที่ซื้อแล้ว ไปจนถึงฝั่งครีเอเตอร์ (ลงขาย แดชบอร์ด โปรโมต แชตจ้างงาน) และระบบหลังบ้านตรวจลิขสิทธิ์

**ดูออนไลน์:** https://songyisong88.github.io/lumi-app/ (เปิดบนมือถือจะแสดงเต็มจอ บนคอมพิวเตอร์มีเมนูลัดไปทุกหน้าจอ)

## ข้อควรทราบ
- ข้อมูล ราคา ครีเอเตอร์ และรูปทั้งหมดเป็น **ข้อมูลตัวอย่าง** รูปผลงานสร้างด้วย AI เพื่อใช้ในต้นแบบนี้เท่านั้น
- การชำระเงินทั้งหมดเป็นการจำลอง ไม่มีการตัดเงินจริง (QR พร้อมเพย์เป็นภาพตัวอย่าง ห้ามสแกน)
- รหัส OTP ตัวอย่าง: `123456` · โค้ดส่วนลดตัวอย่าง: `LUMI50`
- ตะกร้า การซื้อ และรายการโปรดเก็บไว้ในเบราว์เซอร์ (localStorage) กด "ล้างข้อมูลและเริ่มใหม่" เพื่อรีเซ็ต

## รันในเครื่อง
```bash
python3 -m http.server 8765
# แล้วเปิด http://localhost:8765/
```
เป็น HTML/CSS/JavaScript ล้วน ไม่ต้อง build ภาพหน้าจอทั้งหมดอยู่ในโฟลเดอร์ `screenshots/` และภาพรวมอยู่ที่ `board-lumi.png`
